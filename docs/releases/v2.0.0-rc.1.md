# Horus v2.0.0-rc.1

This is a public prerelease candidate for dedicated-server validation. `v1.4.3` remains the recommended stable release until the remaining multi-account scenarios are completed.

## Highlights

- Separate `Horus.Shared`, headless-safe `Horus.Server`, and visual `Horus.Client` assemblies.
- Authenticated SteamID64 allowlist with deny-all defaults.
- Versioned Mirage protocol, authoritative command validation, state snapshots, revisions, deduplication, rate limits, and audit logs.
- Dedicated parity for spawning, tactical orders, editing, Live Ordnance, safe deletion, undo/redo, RTS economy, factories, rally points, and persistence.
- Reproducible GM, Dedicated, and Full packages.

## Verified

- Portable logic, protocol, security, paging, state, and audit tests.
- Clean Shared, Client, and Server builds against the installed official game/server assemblies.
- Headless assembly dependency audit.
- Windows headless startup, Steam login, Mirage registration, deny-all allowlist, BuiltIn mission selection, persistence restart, and clean client startup.
- Package layout, embedded checksums, UTF-8/English validation, and byte-for-byte reproducibility.

The exact machine evidence and current status are recorded in [the validation matrix](../validation/release-matrix.json) and [the Windows smoke report](../validation/2026-08-30-windows-smoke.md).

## Pending

- Two simultaneous authenticated GMs and two concurrent Steam identities: a second legitimate Steam account is not available on the validation workstation.
- Any item still marked `PENDING` in the release matrix at publication time.

Pending scenarios are limitations of the available validation infrastructure, not PASS results.

## Known limitations

- This RC must not be described as production-certified.
- A GM joins as a normal Steam-authenticated player and occupies a slot; the incomplete spectator authentication path is not used.
- Normal clients do not need Horus for native content. Third-party content must match on every relevant machine.
- The official TCP administration endpoint is not used for Horus world mutations.

## Checksums

Use the release asset `SHA256SUMS.txt` and verify it before extracting any ZIP. `release-manifest.json` records the source commit, protocol version, reproducible timestamp, artifact sizes, and artifact hashes.

## Rollback

Stop the game/server, remove `BepInEx/plugins/Horus/`, and reinstall the unchanged `v1.4.3` release. Existing tags and assets are never replaced; fixes to this candidate will use `v2.0.0-rc.2` or later.
