# TEST RELEASE — Horus v2.0.0-rc.1

> [!CAUTION]
> **EXPERIMENTAL PRERELEASE — NOT PRODUCTION-CERTIFIED.** This public release candidate is intended for dedicated-server field testing. `v1.4.3` remains the recommended stable release. The connected gameplay scenarios listed under Pending have not passed and must not be inferred from the successful headless tests.

Start with the [complete English user manual](https://github.com/ReapeRAlan/Horus-Mod/blob/v2.0.0-rc.1/docs/user-manual.md). It covers package selection, installation, controls, dedicated authorization, all major workflows, troubleshooting, test reporting, verification, and rollback.

## Highlights

- Separate `Horus.Shared`, headless-safe `Horus.Server`, and visual `Horus.Client` assemblies.
- Authenticated SteamID64 allowlist with deny-all defaults and whole-file rejection on any invalid entry.
- Versioned Mirage protocol, authoritative command validation, validated state snapshots, revisions, per-SteamID deduplication/rate limits, and bounded authenticated rejection auditing that prevents UDP or invalid-session disk amplification.
- Dedicated parity for spawning, tactical orders, editing, Live Ordnance, safe deletion, undo/redo, RTS economy, factories, rally points, and persistence.
- Reproducible GM, Dedicated, and Full packages.

Pending scenarios are limitations of the available validation infrastructure, not PASS results.

## Known limitations

- This RC must not be described as production-certified.
- A GM joins as a normal Steam-authenticated player and occupies a slot; the incomplete spectator authentication path is not used.
- Normal clients do not need Horus for native content. Third-party content must match on every relevant machine.
- The official TCP administration endpoint is not used for Horus world mutations.
- Original mission units cannot be ordered or edited unless the operator separately enables `AllowMissionUnitMutation`; deletion uses its own stricter setting.

## Checksums

Use the release asset `SHA256SUMS.txt` and verify it before extracting any ZIP. `release-manifest.json` records the source commit, protocol version, reproducible timestamp, artifact sizes, and artifact hashes.

## Rollback

Stop the game/server, remove `BepInEx/plugins/Horus/`, and reinstall the unchanged `v1.4.3` release. Existing tags and assets are never replaced; fixes to this candidate will use `v2.0.0-rc.2` or later.
